# Next study: feasibility scoping (2026-11-13)

This is the proposal from `independent_review_response.md` §9, checked against the codebooks and the data on hand. **No outcome
analysis has been run for this study.** Plans are frozen locally (PI decision, 2026-11-13; D-043).

| Component | Proposal | What the data allow | Recommendation |
|---|---|---|---|
| NLSY97 parent support, 1997–2003 (stability, gains, losses; youth fixed effects) | Seven annual reports | The codebook shows the "very supportive" mother item only for 1997–2000, plus a split-sample 2001 experiment. In 1998–1999 it was asked only of youths ≤ 14 at the end of 1996. This is the panel Study 4 already used. | **Drop** as a new component. It would mostly re-analyze Study 4. |
| NLSY79 Children and Young Adults sibling comparison (mother fixed effects) | Separate timing from stable family warmth | Analytic sample: 6,190 children of 3,138 mothers. With the outcome observed: 1,828 mothers have 2+ children (4,533 children). The within-family BA contrast is identified mainly by **484 families (1,250 children) with siblings who differ in BA**. | **Primary AI-run component.** Within-family estimates of praise at 6–9 vs 10–14, with a linear probability model and mother fixed effects; trait–state decomposition of repeated praise reports. Power is limited, so the plan must state the minimum detectable difference before freezing. |
| Add Health Wave III mentor items: onset (`H3MN6`), duration (`H3MN8`), closeness (`H3MN11`), type (`H3MN2`) | Separate onset, duration and quality | Available. Add Health prohibits AI processing, so it is **human-run** as in A3. | **Secondary, human-run component.** Joint model of onset, duration and closeness among the mentored, with a script written from codebooks only. |
| Negative-control outcomes | Detect residual confounding | NLSY79 Children and Young Adults: candidate outcomes determined before the exposure windows (e.g., early-childhood assessments), to be checked in the codebook | Include if a pre-exposure outcome is available. |

## Decisions needed from the PI before a plan is frozen

1. **Scope:** whether to proceed with the sibling (AI-run) and Add Health (human-run) components.
2. **Margin:** for the sibling contrast, the equivalence margin, as signed off for earlier studies (D-011).
